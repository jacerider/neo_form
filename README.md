## INTRODUCTION

Provide functionality for controlling forms.

## REQUIREMENTS

This module requires Neo, Neo Color and Drupal core. And assumes you are using
the Front and Back Neo themes.

## INSTALLATION

Install as you would normally install a contributed Drupal module.
See: https://www.drupal.org/node/895232 for further information.

## CONFIGURATION

Visit /admin/config/neo/form to configure forms.
